# M3 玩家防御与锁定

## Arena 试玩

M4 起 Arena 默认启用暗影剑客。练习以下木桩操作时，先停用 `ShadowSwordsman`，再启用 `TrainingDummy`。

1. 打开 `Assets/_Project/Scenes/Arena.unity` 并进入 Play 模式。让木桩进入视野，按鼠标中键锁定。木桩头顶出现标记，镜头同时照到玩家和目标。
2. 锁定后按 A / D 环绕，W / S 靠近或拉远。角色移动时仍面向木桩，攻击前摇会转向目标。空格带方向时按输入方向翻滚，锁定时无方向翻滚会后撤。再次按中键可解锁，目标死亡或距离超过 18m 时也会解锁。
3. 靠近木桩等它出拳。陪练可在 `TrainingDummy` 的 Inspector 中通过 `Sparring Enabled` 开关。普通受击会扣血并打断当前动作，硬直持续 0.4 秒，0.25 秒起可以用翻滚提前脱离。
4. 对着出拳倒计时试两种防御。翻滚在 0.05～0.35 秒有无敌帧，完美闪避返还本次体力。切手技或重击出手后前 0.2 秒内受击会识破，玩家闪青光并立即反击。攻击实际命中时会有短顿帧和轻微震屏。

胶囊占位角色用位移、闪光和状态文字展示动作。Humanoid 模型可选配 `Hit.fbx` 和 `Roll.fbx`。当前 Arena、玩家和木桩预制体已接线，直接打开即可试玩。需要重建时可通过 `Tools/BossFight/Build All` 生成。

## 系统分工

| 类 | 职责 |
|---|---|
| `LockOnTarget` / `LockOnTargeting` | 敌方标记定义瞄准点，玩家组件在中键按下时选取 14m 内、屏幕内且无遮挡的目标 |
| `PlayerMovement` | 自由视角以相机为参照，锁定时以玩家到目标的方向为参照 |
| `OrbitCameraInput` | 在同一个 Cinemachine 轨道相机里平滑调整水平轨道和注视点，复用相机避障 |
| `PlayerHitState` | 处理普通受击硬直和翻滚取消，借助状态退出关闭旧攻击的 Hitbox |
| `LocalHitStop` | 冻结角色动作时钟和 Animator，默认持续 0.035 秒 |
| `CombatImpactFeedback` / `HitFlash` | 订阅 `DamageReceiver.Damaged`，驱动顿帧、Cinemachine Impulse 和闪光 |

锁定参数在玩家的 `LockOnTargeting`，受击时序在 `PlayerCombatConfig`，顿帧和震屏参数在各角色的 `CombatImpactFeedback` 与 `CinemachineImpulseSource`。Cinemachine 的 Source 和 Listener 分别负责广播和接收震动。 [Unity Impulse 文档](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineImpulseSource.html)

## 自动验证

在 Unity 打开 Window → General → Test Runner，切到 PlayMode 运行全部。用例覆盖 M2 攻击回归、锁定取景和环绕、解锁、识破只抵消一击、受击打断、翻滚取消与局部顿帧。

## 面试问答

### 锁定后怎样做到按 A / D 绕目标移动？

将玩家到目标的向量投影到水平面，归一化作为前向，旋转 90° 得到右向。移动输入用这组基向量计算位移，角色朝向单独对齐目标，所以横移时仍能面向对手。相机和移动读取同一个锁定目标。

### 为什么受击硬直接在伤害结算之后？

翻滚和识破先在 `IDamageModifier` 里决定是否化解这次伤害。只有实际扣血才进入受击状态，旧状态的 `Exit` 统一关闭 Hitbox。这样成功识破保留反击，窗口外受击则能中断出招。

### 顿帧如何与慢动作共存？

用真实时间决定短暂停何时结束，用角色的动作时钟驱动前后摇和无敌帧。暂停时该角色的动作时钟不前进，Animator 暂停。全局 `Time.timeScale` 由慢动作系统独立控制，相机仍可更新。
