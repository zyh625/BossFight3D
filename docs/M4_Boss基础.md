# M4 暗影剑客 Boss

## Arena 试玩

当前 Arena 还包含 M5 技能。远程招式和二阶段的验收见 [M5 试玩步骤](M5_Boss技能与二阶段.md)。

1. 打开 `Assets/_Project/Scenes/Arena.unity` 并进入 Play 模式。暗影剑客会主动追击。中键锁定，留意胸口的橙色蓄力提示和屏幕上方的状态。
2. 三连斩依次是左剑、右剑、双剑交叉斩。前两刀前摇 0.45 秒和 0.35 秒，第三刀延迟至 0.75 秒，提示更亮，收招留出 1 秒。站在攻击范围内会依次受到 12、12、24 点伤害。可用翻滚躲开，也可迎着出招识破。
3. 在 Boss 追击或等待时进攻。Boss 格挡时承受 20% 的生命伤害，格挡条会随攻击下降。识破后的强化反击在 Boss 出招时也能削条。普通攻击适合趁收招打生命伤害。
4. 格挡条见底会进入 3.5 秒破防。破防期间普通伤害 ×1.5，蓄力重击 ×2.5。随后进入约 6 秒的虚弱期，格挡条回满前无法格挡，强化反击和蓄力重击可打断虚弱期前摇。
5. Boss 倒下后锁定解除。胜利或战败面板出现后，点击 **再战一局** 即可重开。见 [M6 试玩步骤](M6_战斗界面与流程.md)。

Arena 默认启用 `ShadowSwordsman`。要使用 M2/M3 练习，在 Play 模式下先停用 `ShadowSwordsman`，再启用 `TrainingDummy`。当前采用程序化双剑和胶囊体，已有 Arena 直接可玩。搭建脚本可通过 `Tools/BossFight/Build All` 生成相同结构。

## 系统分工

| 模块 | 职责 |
|---|---|
| `BossController` | 组装状态机，处理守势、破防、受击打断和战斗结束 |
| `BossBrain` | 按攻击距离和冷却判断能否发起三连斩 |
| `BossApproachState` / `BossComboState` / `BossStaggerState` | 追击、逐刀推进、受击与破防 |
| `BossCombatConfig` / `AttackData` | Boss 移速和伤害倍率，三刀各自的前摇、判定、后摇和踏步 |
| `GuardMeter` | 保存格挡条，普通恢复等 4 秒后以 10 点/秒进行，破防结束后在虚弱期回满 |
| `BossWeaponRig` | 程序化双剑姿态、蓄力灯和独立的攻击扫掠轴 |

各刀参数在 `Assets/_Project/Data/Attacks/Boss_*.asset`，AI 与增伤参数在 `BossCombatConfig.asset`，格挡恢复可在 Boss 预制体的 `GuardMeter` 调整。

## 验证

Unity 菜单 Window → General → Test Runner → PlayMode。Boss 用例覆盖追击、三刀的伤害和节奏、格挡扣条和恢复、识破反击破防、破防增伤、虚弱打断与死亡清理。玩家回归用例会切换到同场景内的训练木桩。

## 面试问答

### Boss 为什么把决策和招式执行分开？

`BossBrain` 只在追击状态决定能否发招，招式开始后交给状态机按 `AttackData` 执行。玩家离开攻击距离时，当前连段依旧完整执行，落空由武器判定决定。新增招式时可扩展决策规则并复用伤害结算。

### 一次命中怎样触发破防和后续增伤？

`IDamageModifier` 先扣格挡并结算当次命中。打空格挡的命中仍按它开始时的格挡状态处理。结算完成后状态机才切到破防，所以之后的命中才获得增伤。识破反击携带独立的攻击标记，可以在 Boss 出招时扣格挡。

### 双剑为什么不会让第三刀扣两次血？

两把剑共用一条逻辑扫掠轴。每刀只开启一次 `Hitbox`，同一个受击者在这次挥砍里会被去重。状态切换会关闭判定，Boss 被打断或倒下后也能立即清理。
