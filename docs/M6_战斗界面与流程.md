# M6 战斗界面与流程

## Arena 试玩

1. 打开 `Assets/_Project/Scenes/Arena.unity`，进入 Play 模式。顶部显示 Boss 的生命、格挡、阶段和出招提示。左下角显示玩家生命、体力和空的特殊技占位条。蓄力和识破后的免体力倒计时按需出现。
2. 在 Boss 破防期间打中一记蓄力重击。镜头短暂对准交战位置并拉近，命中带金色闪光和 0.25 秒局部顿帧。若这一击击败 Boss，镜头结束后显示胜利面板。
3. 胜利或战败时，鼠标自动释放。点击 **再战一局** 重新载入 Arena，可检查玩家和 Boss 的血量、体力、格挡及阶段是否复位。
4. 如需练习木桩，在 Play 模式下停用 `ShadowSwordsman` 并启用 `TrainingDummy`，继续使用训练调试面板。

界面由 Editor 搭建脚本生成。现有 Arena 已接线，可直接试玩。HUD 中文优先使用系统安装的微软雅黑等字体。 [Unity 系统字体接口](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Font.CreateDynamicFontFromOSFont.html)

## 系统分工

| 模块 | 职责 |
|---|---|
| `FightDirector` | 监听双方生命的死亡事件，结算胜负、结束玩家操作、释放鼠标，重载当前 Arena |
| `FightHud` / `BarView` | 读取生命、体力、格挡与锁定目标，在 Canvas 上显示 |
| `FightResultView` | 显示结算面板，启用 UI 输入并绑定重开按钮 |
| `FinisherCamera` | 根据破防重击结果暂时接管镜头注视和视野，播放完后还原 |
| `CombatImpactFeedback` / `HitFlash` | 根据同一命中结果应用强化顿帧、镜头脉冲和金色闪光 |

## 自动验证

Unity 菜单 Window → General → Test Runner → PlayMode。新增用例验证 HUD 同步、战败与按钮重开、致命破防重击先播放特写再弹出胜利，以及同帧双方倒下时的结算优先级。

## 面试问答

### 为什么胜负到帧末才确定？

死亡事件记录本帧发生了伤害结果，帧末统一读取双方生命。这样同帧两边倒下时按固定规则判负，结果与两个命中回调的先后顺序无关。

### 为什么重开直接重新加载场景？

场景里的生命、体力、格挡、AI 冷却、投射物、镜头和输入各自按原有入口初始化。重载场景让它们一起复位，避免遗漏某个运行时对象。

### 谁决定一击是不是破防重击？

Boss 的伤害结算器同时看到破防状态和蓄力重击类型，于是给结算结果加上破防重击标记。镜头、闪光和顿帧只读取该标记。特写用真实时间还原视野，局部顿帧不改变全局时间。
