# M5 Boss 技能与二阶段

## Arena 试玩

1. 打开 `Assets/_Project/Scenes/Arena.unity` 并进入 Play 模式。出生距离约 6m，可以看到 Boss 压低剑身蓄光后发出贴地剑气。横向翻滚或迎着命中时刻识破。剑气最多飞行 14m，伤害从 28 线性降到 10。
2. 与 Boss 拉开 7m 以上的距离可诱发瞬身斩。超过剑气出招距离时，瞬身斩是唯一可用的远程招式。Boss 原地蓄力后出现在玩家上方，地面圈锁定，滞空 0.4 秒后下劈。滚出圈即可避开 32 点伤害。
3. 在 Boss 格挡或追击时连续命中，观察它带着光带后撤。后撤位移阶段能躲伤害，收招时可以追击。场地墙壁会挡住后撤位移。
4. 将 Boss 打到半血。若该击未致死，Boss 会打断当前动作，格挡回满，震退附近玩家，并获得 2 秒无敌。转阶段后胸口常态发光为品红，技能冷却乘以 0.65，三连斩前两刀前摇乘以 0.85。

屏幕上方的调试条显示招式名称、前摇和转阶段倒计时。地面圈、剑气和后撤光带使用程序化占位表现。Boss 预制体已接线，打开现有 Arena 即可试玩。

## 系统分工

| 类 | 职责 |
|---|---|
| `BossBrain` | 按距离和独立冷却筛选主动招式，再按权重抽取。上次用过的主动招式权重减半。后撤概率在连续受击时单独判定 |
| `BossBlinkSlashState` | 处理原地蓄力、锁定落点、滞空、落地判定和退出清理 |
| `BossSwordWaveState` / `BossSwordWave` | 分离蓄力和投射物。投射物沿一帧跨过的整段扫掠，按飞行距离结算一次命中 |
| `BossRetreatState` | 使用角色碰撞控制器后撤，限制位移期间的闪避窗口 |
| `BossPhaseState` | 回满格挡、推开附近玩家、显示能量圈。结束时回到决策 |
| `BossSkillVisuals` | 生成落点圈、后撤光带和贴地剑气的占位效果 |

技能距离、冷却、权重、位移、判定和转阶段参数在 `Assets/_Project/Data/BossCombatConfig.asset` 的 `Skills` 下。动作时序使用角色动作时钟，发射后的剑气独立使用游戏时间。

## 自动验证

Unity 菜单 Window → General → Test Runner → PlayMode。技能用例验证剑气衰减和单次命中、瞬身斩固定落点和脱离范围、后撤闪避窗口，以及转阶段打断、回盾、无敌、击退和前摇加快。原有玩家和 Boss 基础用例继续参与回归。

## 面试问答

### 为什么落点要在滞空开始时锁定？

地面提示圈必须代表真正的伤害范围。进入滞空时保存一次目标位置，之后视觉和判定都读这个值。玩家移动后，Boss 仍落向旧位置，走位才有意义。

### 剑气为什么每帧扫过整段距离？

固定速度的剑气在低帧率时可能一帧跨过玩家。用覆盖上一帧到当前帧的盒体查询 Hurtbox，命中后记录结果，便能在不同帧率下维持一次命中。伤害仍由统一伤害管线处理，能被识破和翻滚化解。

### 转阶段怎样避免旧招继续伤人？

血量事件切到转阶段时，状态机会先执行旧状态的退出，关闭近战 Hitbox 或落点判定。场上的剑气在检测到转阶段时销毁，新的状态独立负责无敌和计时。二阶段冷却应用到剩余时间和之后的招式。
